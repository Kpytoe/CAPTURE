# Captura Local

Capturas de pantalla para Windows 10 / 11 de 64 bits. Un solo archivo, sin instalar nada.

## Descargar

1. Descarga **[CapturaLocal-win-x64.zip](https://github.com/Kpytoe/CAPTURE/releases/latest/download/CapturaLocal-win-x64.zip)**.
2. Clic derecho sobre el `.zip` → **Extraer todo**.
3. Abre `CapturaLocal.exe`. Puedes dejarlo en la carpeta que quieras.
4. La aplicación queda en la **bandeja del sistema** (junto al reloj; en Windows 11 puede estar
   detrás de la flecha `^`). Pulsa `Ctrl+Shift+2` para capturar.

## Si Windows o el navegador lo bloquean

El archivo no está firmado, así que es normal que salte algún aviso:

- **«Windows protegió su PC»** al abrirlo → **Más información** → **Ejecutar de todas formas**.
- **El navegador no deja descargarlo** («no se descarga habitualmente», «archivo peligroso») →
  en la lista de descargas, abre el menú `…` del archivo → **Conservar** → **Conservar de todos
  modos**.
- **Sigue sin abrir** → clic derecho sobre `CapturaLocal.exe` → **Propiedades** → marca
  **Desbloquear** → **Aceptar**.
